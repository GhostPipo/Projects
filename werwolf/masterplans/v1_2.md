## Phase 3: Datenbankanbindung & RESTful API (AKTUELLE PHASE)
- [ ] **Datenbankverbindung:** In der `server.js` via `mongoose.connect(process.env.MONGO_URI)` eine Verbindung zu MongoDB Atlas herstellen.
- [ ] **Routing-Setup:** Ordner `routes/` erstellen und `gameRoutes.js` anlegen. Diese in der `app.js` unter `/api/games` einbinden.
- [ ] **CRUD Endpunkte implementieren (`gameRoutes.js`):**
  - `POST /` (Create): Neue Lobby erstellen.
  - `POST /:room_code/players` (Create): Spieler tritt bei.
  - `GET /:room_code` (Read): Spielstatus für Polling abrufen.
  - `PATCH /:room_code` (Update): Spielzustand ändern (Phase, Tote, etc.).
  - `DELETE /:room_code` (Delete): Lobby auflösen.
