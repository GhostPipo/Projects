# Masterplan: Werwolf Refactoring & MongoDB Migration

## Phase 1 & 2: Architektur & Datenmodell (Abgeschlossen)
- [x] `.env`, Trennung `app.js`/`server.js`, `models/Game.js` erstellt.

## Phase 3: RESTful API & In-Game Logik (In Arbeit - Zielgerade)
- [x] Create (Lobby erstellen), Join (Beitreten) und Read (Status Polling) sind implementiert und funktionieren ohne 404.
- [ ] **Spiel-Aktionen migrieren (Updates):** Die restlichen alten Aktionen auf REST umstellen.
  - `start_game`: Rollen verteilen, `game_phase` auf 'night' setzen.
  - `next_phase`: Zwischen Tag und Nacht wechseln, Timer zurücksetzen.
  - Rollen-Aktionen (`wolf_vote`, `witch_heal`, `witch_kill`, `seer_look`): Den Status einzelner Spieler im Sub-Dokument aktualisieren (`is_alive` ändern, `has_potion` anpassen etc.).
  - Diese Aktionen sollten über die `PATCH /api/games/:room_code` Route (oder semantisch saubere Sub-Routen wie `POST /api/games/:room_code/actions`) abgewickelt werden.

## Phase 4: Frontend Templating (Ausstehend)
