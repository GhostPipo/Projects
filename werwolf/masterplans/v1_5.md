# Masterplan: Werwolf Refactoring & MongoDB Migration

## Phase 1 bis 3: Architektur, MongoDB & REST API (Abgeschlossen) ✅
- [x] Architektur getrennt (`app.js` & `server.js`).
- [x] Datenbank (`MongoDB Atlas`) via `mongoose` angebunden.
- [x] CRUD-Operationen & In-Game-Aktionen laufen komplett über saubere REST-Endpunkte (`/api/games/...`).

## Phase 4: Frontend Templating (AKTUELLE PHASE)
- [ ] **`index.html` anpassen:** Die statischen HTML-Strukturen, die bisher im JavaScript zusammengebaut wurden, als unsichtbare `<template>`-Tags im HTML-Dokument definieren.
  - Template für die Spielerliste (Lobby).
  - Template für das Aktions-Grid (wer kann wen anklicken).
  - Template für die Rollen-Karten / den Game-Over-Screen.
- [ ] **`js/script.js` refactoren:** - Das alte `innerHTML += "<div class='player'>..."` komplett entfernen.
  - Stattdessen das HTML-Template klonen (`content.cloneNode(true)`), die dynamischen Daten (Name, Rolle, Status aus der MongoDB-Antwort) per `textContent` oder `classList` einfügen und in den DOM einhängen.
- [ ] **Keine externen Libraries:** Es darf ausschließlich natives Vanilla JavaScript und natives HTML5 verwendet werden (kein EJS, Pug, Handlebars, React etc.).
